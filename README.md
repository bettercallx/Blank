# Blank

Blank — 像素风专注计时器

## 本地开发

```bash
npm install
npm run dev
```

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/bettercallx/blank.git
git push -u origin main
```

GitHub 仓库 → Settings → Pages → Source 选 "GitHub Actions"

## iPhone 使用

Safari 打开网址 → 分享 → 添加到主屏幕
